# Расписание МАДИ

Приложение для просмотра расписания занятий и экзаменов МАДИ на Android и Windows.
Данные загружаются с [сайта МАДИ](https://raspisanie.madi.ru/).

[Google Play](https://play.google.com/store/apps/details?id=com.wildchair.schedulemadi) · [RuStore](https://www.rustore.ru/catalog/app/com.wildchair.schedulemadi) · [GitHub Releases](https://github.com/wildchair/ScheduleMADI/releases/latest)

[Сообщить об ошибке](https://github.com/wildchair/ScheduleMADI/issues)

## Возможности

- Поиск группы или преподавателя.
- Предметы, время занятий, аудитории и преподаватели.
- Выбор даты в календаре и учёт числителя и знаменателя.
- Расписание экзаменов, когда оно опубликовано на сайте МАДИ.
- Сохранение выбранной группы или преподавателя между запусками.

## Разработка

Проект написан на C# и .NET MAUI 10. Для сборки нужны SDK из [global.json](global.json) и рабочие нагрузки соответствующей платформы.
